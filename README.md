# Windows & Doors — Design Review

A public, unbranded static design review. No products or services are offered.
Original schematic SVG illustrations are included; they are not product imagery or technical drawings.

Open index.html or serve this directory with a static HTTP server. Relative asset paths support the existing /Window/ GitHub Pages route. The site has no form, checkout, analytics script or external runtime dependency. The blank checklist downloads locally; nothing is submitted by the site.

The gh-pages branch contains only the public review. Business identity, products, services and contact information need separate confirmation before any operating business website is launched.
